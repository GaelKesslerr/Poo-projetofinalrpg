# SOBRE O PROJETO

## Este projeto consiste no desenvolvimento de um sistema de RPG utilizando Python e os conceitos de Programação Orientada a Objetos (POO).

O sistema representa personagens e monstros de um universo de fantasia, permitindo explorar características, ataques e habilidades especiais de cada tipo.

# OBJETIVO

O objetivo do projeto é aplicar conceitos como herança, polimorfismo e reutilização de código, criando diferentes classes de personagens e monstros com características e comportamentos próprios.

# Classes

## Cada classe é separada por nível, vida(aka HP), ataque, defesa e reino.

# Herói

Representa o personagem principal

## Guerreiro

Representa o personagem especializado em combate corpo a corpo

## Mago

Representa o personagem que utiliza mana e habilidades mágicas.

## Arqueiro

Representa o personagem especializado em combate a longa distância, permitindo a causa de danos críticos

# Montros!

Os inimigos do jogo, personagens com quem os heróis devem lutar contra.

## Golem

São enormes estátuas de sencientes de material rochoso, sua habilidade sendo sua grande resistência temporária contra grandes ataques

## Mortos-vivos

São criaturas amaldiçoadas que voltaram da vida pós morte, contém habilidades especiais.
